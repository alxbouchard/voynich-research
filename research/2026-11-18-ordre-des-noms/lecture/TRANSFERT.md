# Lire d'autres noms si les dessins avaient changé d'ordre

Les deux seules tables injectives du calcul sur deux noms ont manqué la troisième inscription ou rencontré une légende composée. Nous les fixons néanmoins telles quelles pour tester l'hypothèse distincte d'une liste remaniée. Avant de compter de nouveaux emplacements, énumérer tous les noms entiers que ces tables peuvent écrire dans la même langue : répertoire Carrara pour l'italien, titres du Macer et du Gart pour le latin. Une nouvelle forme exclut les deux noms d'amorce, y compris leurs doublons. Publier les orthographes EVA imposées.

En réserve, retirer les deux feuillets physiques f88 et f89 entièrement. Compter pour le cahier 19 toutes les légendes végétales Lf à un groupe concordant dans les quatre lectures, même si leur attache à un dessin numéroté reste incertaine. Calculer la couverture de chaque table figée (mots entièrement décodables), donner les formes produites et les nouvelles concordances exactes avec les noms dans la langue choisie. Pour les deux premiers mots ayant servi de point de départ, séparer une reprise de l’amorce d’une lecture nouvelle. Comparer le nombre de nouvelles graphies en faisant toutes les permutations des lettres déjà connues entre les signes déjà connus. Dans chaque permutation, retirer les deux graphies EVA de départ et les deux noms historiques de départ, afin de comparer le même problème. Donner un résultat même si aucune nouvelle graphie n'est prédite. Un herbier peut omettre des plantes connues des modèles ; une absence ne désigne pas une langue. Si un nom nouveau est retrouvé, vérifier le parchemin et sa relation avec le dessin en gardant les identifications incertaines.
