# Attribution et périmètre

Les sources `upstream/xib` et `upstream/dev_misc` proviennent des dépôts publics de Jiaming Luo, aux commits inscrits dans `source_manifest.json`. Elles sont conservées comme pièces de recherche locales ; aucune nouvelle licence n'est attribuée à ces fichiers. Les notes de dépôt dans `source_notes` conservent les crédits de leurs auteurs.

Référence scientifique : Jiaming Luo, Frederik Hartmann, Enrico Santus, Regina Barzilay et Yuan Cao, *Deciphering Undersegmented Ancient Scripts Using Phonetic Prior*, TACL 9, 69–81, 2021, https://aclanthology.org/2021.tacl-1.5/.

Le fichier ougaritique est celui de `j-luo93/NeuroDecipher`, commit `480bad2487820e3737fecfdd108214efa769e34b`. L'inventaire distingue ce matériau ACL 2019 des transformations attendues par TACL 2021.

Les mots de `smoke_data` sont des chaînes artificielles créées pour vérifier le programme. Aucun passage historique n'est traduit. Les checkpoints de `smoke_runs` ont été produits localement par ces trois essais ; aucun checkpoint tiers téléchargé n'a été désérialisé.
