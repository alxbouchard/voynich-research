# Sources et crédits

Photographies : **Beinecke Rare Book & Manuscript Library, Yale University, MS 408**. Les six JPEG natifs proviennent de Yale ; leurs empreintes correspondent à l'inventaire antérieur du projet. Les aperçus sont réduits, les huit détails sont des cadrages sans changement des pixels.

[Références et SHA-256](../docs/PIECES_REFERENCES.md#piece-340f5a2cda2458) : f99r/1006246, f99v/1006247, f100r/1006248, f100v+f101r/1006249, f101v partiel+f102r/1006251 et f102v2/1006252. Les URL canoniques sont conservées dans ce fichier.

Correspondances publiées : René Zandbergen, [cahier 19](https://www.voynich.nu/q19/index.html), consulté le 17 novembre 2026. Aucun nom botanique n'est repris comme vérité. Pour l'attribution conditionnelle de 188 : [relevé interlinéaire f101v2](https://www.voynich.nu/q19/f101v2_tr.txt), section R1.7, avec contexte introductif. Ce texte a été lu via l'accès web ; le téléchargement HTTP brut a échoué. [INTERLINEAR_REFERENCE.json](../docs/PIECES_REFERENCES.md#piece-7e38ff34867c0f) conserve la référence, un bref extrait et les variantes utiles, sans prétendre archiver le fichier intégral.

Transcriptions conservées sans changement : ZL version 3b du 13/05/2025, issue d'EVMT ; IT version 2a du 02/02/2023 modifiée le 25/06/2025, extraite de LSI_ivtff_0d.txt. Les en-têtes originaux sont préservés.

Le compte rendu spatial original conserve les chemins temporaires utilisés par le lecteur. Ses huit détails sont maintenant copiés dans evidence/ ; leurs coordonnées et leur statut d'ajout d'archive figurent dans [CROP_GEOMETRY.json](evidence/CROP_GEOMETRY.json). Ils ont été examinés avant le gel, mais leurs copies finales ne sont pas incluses dans FREEZE.json. Les sources et le compte rendu le sont. MANIFEST.json couvre la livraison finale.
